# Receipts v1.0.0 — Clock In submission

**Receipts** turns every crypto price call into an on-chain receipt: sealed as a hash now, revealed after the deadline, scored against the market. Unrevealed calls count as misses — your record can't be cleaned up.

## Install
1. Download `receipts-<date>.apk` below to an Android phone (built for Solana Seeker; any Android 10+ with a Mobile Wallet Adapter wallet works).
2. Allow "install unknown apps" for your browser/files app, open the APK.
3. No wallet or SOL? Tap **Try demo (no wallet)** — simulated data, clearly labelled, nothing is signed or sent.

## What's inside
- Up/down calls on **SOL** (Pyth) and **SKR** (KuCoin SKR-USDT) with 24h / 3d / 7d horizons, 1h practice and the shared **SKR Daily Call**.
- Commit–reveal on Solana with SPL Memo + a 0-lamport registry tag. No custom program, no backend, no funds held.
- Secrets derived from your wallet signature → reveal from any phone.
- Rating = σ vs coin flip; leaderboard needs ≥ 10 calls on ≥ 3 days and a Seeker Genesis Token. Hedging both sides gives a coin flip, not a win.
- Night Register pixel theme, parallax, Chekko the register mimic, receipt-printing reveal ceremony, SKR tips.

Signed with the project's own release key (SHA-256 `21:5D:21:AC:89:A9:3E:53:6E:0E:80:9C:85:CE:03:63:50:86:67:F8:CE:48:64:3D:71:27:15:06:3F:5D:E3:44`).
